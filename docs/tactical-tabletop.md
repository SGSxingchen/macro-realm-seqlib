# 界域战术桌：首版实现与验证

## 入口与边界

独立入口 `/tabletop.html`，房间地址 `/tabletop.html?room=...`。使用 Vite 多入口构建，战术桌的 Konva 代码和样式不进入序列库阅读应用的业务包，避免和阅读布局 PR #4 争用 App 路由。原导航仅增加入口链接。

这是通用战术记录工具，不是规则引擎。自由坐标以米为单位；没有自动 AP、伤害、命中、冷却、视线、碰撞或移动合法性判断。技能与状态不要求任何序列库模板。

## 已实现范围

- 房间创建、玩家/只读观战邀请、24个独立成员身份、服务器分配控制权、撤销成员。
- 多场景、PNG/JPEG/WebP底图与棋子头像、可选网格/吸附、直接尺寸和两点比例尺校准。
- 文字/头像棋子、单选/框选/Shift多选、批量移动、复制、删除、锁定、朝向与自由体型/高度说明。
- 圆、矩形、扇形、线形、多边形范围。范围可固定或跟随棋子，手动取消“生效”只弱化显示、不删除对象。
- 直线/折线本地测距。所有距离为平面世界坐标距离；不自动解释体型边缘、穿墙、跳跃或攻击可达性。
- 任意名称计数器（数值、负值和“无限”均作为文字记录）、状态、公开备注、主持人私密备注、规则原文与资料来源。序列库路径可以新标签页打开。
- 手动轮次/当前行动者/行动排序；下一位不恢复AP，不扣冷却，不清状态。
- WebSocket过滤快照、HTTP事务命令、独立镜头、断线暂停修改与重连、SQLite持久化、受版本保护的对象撤销、含图片JSON备份导入导出。
- 桌面一行48px主栏，工具窄栏，属性面板按需打开；窄屏面板在底部，鼠标与触控地图交互。

## 启用（必须由维护者配置）

安装现有后端 requirements.txt（新增 Pillow）与前端 `npm ci && npm run build`。后端仍使用 `app.main:app`，只新增独立路由，不修改已有序列库接口。

```
TABLETOP_CREATE_KEY=<独立且足够长的建房口令>
TABLETOP_DATA_DIR=<持久、本机磁盘目录，例如 /var/lib/macro-realm/tabletop>
# 仅当代理后的 scheme/Host 不等于浏览器 Origin 时，明确列出允许的公开来源：
TABLETOP_ORIGINS=https://trpg.chordvers.org
```

缺少建房口令时，创建房间返回503，现有房间不受影响。口令不等于网站后台密码，不发给玩家；玩家只使用房间邀请。生产必须使用 HTTPS，Cookie 路径按房间隔离，HttpOnly、SameSite=Strict，在HTTPS请求上设Secure。通过受信任代理正确配置 Uvicorn proxy headers，不信任任意客户端提供的转发头。

反向代理应将 `/api/tabletop/` 转给同一后端，支持 WebSocket Upgrade（HTTP/1.1、Upgrade、Connection），空闲超时大于心跳间隔。前端静态服务器应实际提供构建出来的 `tabletop.html`，不要把这个文件重写成序列库 index.html。

本PR不自动修改线上服务配置、密钥或部署。合并本身可能触发现有仓库部署工作流；因此应由维护者确认配置和测试再自行合并。

## 同步与安全模型

SQLite事务是唯一共享状态权威。每个对象使用全局单调修订号作为CAS版本，批量移动在一个事务里完成。过期操作返回409，不采用整房间“最后写入者覆盖”。命令有持久幂等ID，相同ID不同内容拒绝。写入提交后才返回成功；网络异常时前端明确标记“结果未确认”，不盲目重放旧操作。

WebSocket是出站状态/心跳通道，修改只走已鉴权的HTTP命令。每个连接约350ms读取过滤快照；同一机器的多个服务进程共享同一个SQLite目录，不依赖进程内广播列表。不是多节点集群架构；不在NFS上部署SQLite，不声称高并发性能已压测。Uvicorn建议 `--ws-max-size 1024`，代理另设请求体/连接速率限制。

主持人可见所有当前场景对象。玩家只能编辑自己被授权且未锁定的对象，观战只读。全体/仅KP/指定成员可见独立于控制权。未授权对象、其锚定范围、私密备注、未发布场景以及不可见头像不会发给玩家；图片读取同样鉴权，no-store，且不支持任意外链URL或原始SVG上传。图片解码后重新编码PNG，去除元信息。服务端验证来源与每次操作权限，撤销成员同时删除会话、连接租约和对象授权。

已经公开并下载的信息无法从玩家缓存、记忆或截图里撤回。底图完整共享，隐藏单位不是地图雾战；请上传玩家可看的底图。

## 保存、身份与撤销

房间/图片/命令回执在TABLETOP_DATA_DIR下的SQLite数据库，必须持久挂载且备份，不提交到Git。数据库含会话凭证哈希；API导出不含会话或邀请凭证。主持人浏览器身份有效30天，当前未提供账号绑定、跨设备主持人恢复或转移；请保留浏览器数据，定期导出内容备份。丢失身份时由站点维护者处理，不能通过填写同名昵称冒充。

对象编辑可撤销自己的最近一笔；若对象被其他人继续修改、权限失效或产生跟随依赖，撤销拒绝，不覆盖别人。仅保留房间最近200个修订范围内的对象撤销历史。没有Redo。场景/成员/导入操作不在对象撤销范围，删除场景需要显式确认与整个房间最新修订号。

备份包含隐藏对象/私密备注，请只由KP保管。导入为新场景、不覆盖旧场景；重建对象/场景/图片ID，清除旧人员分配，所有导入对象先设为仅KP可见，需手动重新公开。底图在切换新场景时对成员共享。

技术容量：200房间/服务器、20场景/房间、500对象/场景、100对象/单次批量、24成员身份（含撤销）、80图片/80MB素材每房间、单图5MB且1600万像素以内。并非游戏规则上限。没有自动清理旧房间或未引用素材，维护者需管理容量。

## 验证命令

```
python -m pytest -q tests/test_tabletop.py
python tests/tabletop_protocol.py
cd web/frontend && npm ci && npm run build
cd ../..
python tests/tabletop_browser.py
```

浏览器测试需要 Python playwright 与 Chromium（`python -m playwright install --with-deps chromium`）。测试脚本启动独立临时数据目录和两个真实Uvicorn进程、三个隔离浏览器上下文，不替换或mock战术桌API/WebSocket。只杀测试脚本自身创建的进程组。覆盖创建/加入、画布拖动、真实同步、权限与隐藏帧、图片、CAS、掉线/重连、整个双worker服务重启持久化、对象区域工具、备份导入、撤销身份与多视口布局；测试数据不来自用户规则书。

浏览器实测的结果以当前PR的CI日志为准。截图和几何指标存 `web/frontend/test-results/tabletop/`。本地构建/单测不替代多浏览器验收；不声称真实手机、Safari/Firefox、互联网弱网或生产代理已经全覆盖。
