# 界域档案终端：布局、交互与兼容阅读

## 改动边界

本次只改查询/阅读前端及对应测试。保留 React、TypeScript、Vite、react-window 和原有 FastAPI 契约；不修改 `序列库/`、`荣誉室/` 中的文本，也不修改 CHM/ZIP/Wiki、后台鉴权和发布流程。原 `Reader/parser.ts`、`Structured.tsx` 保留，新的自适应阅读器使用独立、可检验的原文区间模型。

## 布局与视觉

- 宽屏：界域索引 / 搜索结果 / 阅读正文三栏，各自滚动，不再让筛选挤占结果高度。
- 821–1180px：结果和正文两栏，筛选使用原生 modal dialog。
- 820px 及以下：结果与正文分屏。直接看到搜索结果，阅读后返回保留搜索状态；浏览器前进/后退同步 URL。
- 深色界域终端、冷青强调、琥珀规则提示，配套浅色主题。没有外部图片或字体依赖，也没有装饰性持续动画。

## 非标准技能内容

`Reader/adaptive.ts` 将全文切成连续原文区间。每个 section 保存 `start`、`end` 和未经改写的 `raw`，保证 `sections.map(s => s.raw).join('') === content`。

只有明确的名称字段、小节标题参与分段。兼容常见的 `[字段]：`、`【字段】：`、已知裸字段名及已知无冒号字段。未知的显式字段保留；不能识别的内容按原顺序展示，不猜测等级、消耗、冷却或规则归属。空行后的散文以及名称后的非字段文本不会整段套进前一个字段。

复制全文直接使用接口 `content`；复制条目使用原始区间 `raw`，不从展示字段重建、不生成摘要。原文视图和单项原文对照随时可用。模板兼容是展示增强，不是语义解析保证；无法识别的自定义格式可能没有单独目录项，但不会因此丢失正文。

## 交互

搜索输入兼容中文 IME，Ctrl/⌘ K 聚焦，方向键进入/遍历结果，Enter 打开，原生链接保留新标签页行为。列表按 limit/offset 加载更多，虚拟行尺寸固定匹配卡片，不再静默停在 500 条。

资源导航使用 history.pushState，输入筛选使用 replaceState，监听 popstate/hashchange。详情请求取消过期响应，错误与空结果分离，复制失败明确反馈。返回阅读保留当前会话的滚动位置。

目录、文内精确查找、单项复制和分享定位、浏览器本地收藏均可用。分面为零时仍保留已选项，清除全部筛选包含分类条件；重置全部同时清除关键词。

## 验证

在 `web/frontend` 下执行：

```bash
npm ci
npm run build
node --test tests/archive.test.cjs
```

`Frontend archive checks` 工作流在 PR 中执行构建、原文区间测试、完整 `序列库/` TXT 语料回归和 Chromium 浏览器交互回归。浏览器测试工具独立安装在 runner 临时目录，不修改应用依赖或锁文件。

浏览器覆盖 1440、1024、390、320px；检查复制精确性、非标准内容、定位链接、前进后退、详情竞态、超过 500 条的分页、加载失败、复制权限拒绝、IME、移动端筛选焦点与横向溢出。截图及失败证据上传为 `realm-archive-ui` Actions artifact。

浏览器测试使用确定性的只读模拟 API，不代表生产后端、真实设备或全浏览器兼容性实测。工作流不部署、不写仓库、不读取生产密钥。

## 已知边界

收藏只保存在此浏览器，不做账号同步；资源路径改名或重排后，旧收藏/链接可能失效，会显示错误而不自动匹配同名资源。锚点由标题和重复序号产生，标题或同名条目的次序改变后旧锚点也可能失效。全文仍可以通过原文入口查阅。

文内查找是精确文字匹配，不把拼音/模糊命中冒充连续正文命中。新阅读器不自动解释图片、富文本或计算规则，也不做跨资源等级筛选。

回滚时撤销本 PR 的前端提交即可，不涉及数据迁移。
