# 结团统计页 UI 重设计 — 设计文档

日期:2026-06-06
状态:已确认
范围:仅前端(`SessionStats.tsx` + `style.css`),后端零改动

## 背景与目标

现有结团统计页(`/?tab=stats`)是表单式堆叠布局,存在的问题:

- KPI 概览卡只有孤零零的数字,标签挤在数字旁边不可读
- 导入控件(月份/并发/文件/按钮)和「去重」散落在页面顶部,喧宾夺主
- 双列信息平铺、行太长,宽屏下视线跳跃,不符合网页自上而下的扫读主线
- 空状态、表格、列表视觉单调,缺乏层次

目标:改为**仪表盘式布局 + 网页原生阅读逻辑**,统计数据是主角,导入是折叠工具。视觉沿用现有「克制学院派档案馆」设计语言(CSS 变量体系),但去纸质感、用 Sans 数字和现代 web-app 质感。

设计过程中通过视觉伴侣确认了三轮 mockup,最终定稿为 v3(`.superpowers/brainstorm/4456-1780714257/content/web-native-v3.html`)。

## 页面结构(自上而下,主列限宽 880px 居中)

1. **顶栏(一行)**
   - 左:`结团统计` 标题(Sans,18px,700)
   - 月份切换器:`‹ 2026 年 6 月 ›` 分段控件,左右箭头切上/下月,中间点击弹原生 month picker(复用隐藏的 `<input type="month">`)
   - 右:「⬆ 导入战报」主按钮(实底 accent 色)+「↻」刷新 ghost 按钮

2. **导入面板(默认折叠)**
   - 点「导入战报」切换展开/收起;导入进行中强制保持展开,主按钮显示进行态
   - 内容:大拖拽区(拖入 + 点击选择,显示已选 N 个文件)、并发下拉(1-6)、「开始导入」、「去重」(danger 样式,收进此面板)
   - 进度条、结果列表、失败重试:沿用现有逻辑函数,只换样式
   - 导入完成后面板不自动收起;数据刷新照旧自动触发

3. **KPI 四卡**(一行四个,grid)
   - 结构:标签在上(12px muted)、Sans 大数字在下(26px,700,tabular-nums)、次级信息行(11px subtle)
   - 四卡:本月团数 / 玩家人次 / 总游戏小时 / 主持小时(第四张金色 `--warm` 点缀)
   - 次级信息:
     - 本月团数 → `上月 N`(需额外请求上月 overview)
     - 玩家人次 → `去重后 N 人`(取 players.count)
     - 总游戏小时 → `场均 N.Nh`(总时长 ÷ 团数,团数为 0 时显示 `—`)
     - 主持小时 → `上月 N`(同上月 overview)
   - 上月 overview:复用 `/api/session-stats/overview?month=<上月>`,与本月数据并行请求;失败时次级行显示 `—`,不报错

4. **玩家统计**
   - 标题行:`玩家统计` + `N 人` 计数 + 右侧排序胶囊分段控件(游戏时长/游戏次数/主持次数/玩家名,替代下拉框)
   - 表格列:# 排名 / 玩家 / QQ(mono)/ 次数 / 游戏时长(内嵌水平条 + 数值)/ 轮回 / 主持
   - 时长条宽度 = 该玩家时长 ÷ 全月最大时长(全量数据的 max,跨页比例尺一致);前三名排名数字用 `--warm` 色(仅指标类排序时;按玩家名排序时不高亮)。排名 = 当前排序下的全局序号(跨页连续)
   - **翻页:每页 20 条,传统页码条**(`‹ 1 2 3 … N ›`,页数多时省略中段);纯前端切片,总数 ≤20 不渲染页码条
   - 切换月份/排序时重置回第 1 页

5. **团列表**
   - 一行一团:标题(粗,溢出省略)/ KP / PL ×N / 置信度徽章 / 时长 / 行尾小按钮(查看、删除)
   - 置信度徽章配色:≥90% 绿(`--green`)、70–90% 黄(`--warm`)、<70% 红(`--red`)、未标注灰
   - **翻页:同玩家表,每页 20 条页码条**,切月份重置
   - hover 行高亮

6. **团详情**(点「查看」出现,位置不变)
   - 卡片内编辑标题/时长、参与者列表、raw_payload 摘要 —— 逻辑全部不动,只套新样式

7. **异常列表**(最底部)
   - 未登录提示、字段平铺展示逻辑不变,只套新样式

## 空状态

- 玩家表/团列表为空:居中图标 + 引导文案「本月还没有数据,导入战报后这里会出现统计」
- 异常列表未登录:保持「需要后台登录后查看异常列表」

## 改动范围

| 文件 | 改动 |
|---|---|
| `web/frontend/src/components/SessionStats.tsx` | 结构重排:折叠导入面板、KPI 卡(含上月请求)、排序胶囊、前端翻页、空状态。**现有数据请求/导入轮询/编辑/删除逻辑函数不动,只动 JSX 与新增 state**(`importOpen`、`playersPage`、`sessionsPage`、`prevOverview`) |

## 错误处理

- 上月 overview 请求失败 → 次级行显示 `—`,静默(不进 error banner)
- 其余错误路径(导入失败、加载失败、详情错误)沿用现有处理
