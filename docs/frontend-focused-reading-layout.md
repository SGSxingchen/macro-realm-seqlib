# 专注阅读：减少固定顶栏，不压缩规则正文

本轮基于已经合并的 PR #1，单独提交新的布局 PR。不混入下一项独立功能，不修改资源原文、解析规则、历史关联逻辑、后端、依赖或锁文件。

## 布局规则

- 浏览状态保留站点导航和边栏控制；没有打开资源时不进入空白专注页。
- 专注/自动对照专注状态隐藏站点横幅及独立布局栏。标签、对照/历史入口、布局、搜索和退出在同一工作台行里，标签只横向滚动，不因数量或长名称再占一行。
- 固定参照选择、交换主/参照放入“参照设置”弹层，设置时不挤压正文。
- 原来的主/参照说明条整合为各窗格工具栏中的角色标签与当前档案名。即使正文滚动，两端资源身份依然可见。
- 专注工具栏常驻目录、查找、更多。“更多”保留阅读模式、收藏、全文复制、分享和档案信息，随时可访问。
- 移除专注视图内重复生成的大标题、英文眉题、文件元信息和排版说明。仅减少应用生成的装饰/说明，不隐藏源文件中的标题、制作者、更新记录、规则或任意非模板段落。
- 手机打开正文即用紧凑布局，第一行操作、第二行标签（并排时同行提供主/参照切换）、下方一行阅读工具。搜索与返回结果会恢复浏览界面。

## 状态与可访问性

阅读器不因切换密度重新挂载；用当前可见原文区间记录视口位置，避免移除装饰头后突然跳到另一段。现有每资源模式、查找、阅读位置、标签及参照保持机制继续使用。

设置使用原生 dialog：焦点约束、Esc/点击外侧关闭、关闭后返回触发按钮；显示于 top layer，避免被阅读区 overflow 裁切。设置内容超出小屏时内部滚动。设置不通过 hover 才能出现，退出专注始终是明确按钮。

紧凑布局中的主题控制与站点页头同步，不因隐藏/重新显示页头覆盖用户的主题选择。侧栏原有偏好仍独立保存；搜索快捷键会恢复搜索入口。

## 验证

现有原文完整性、全库 TXT、工作台状态和两套浏览器测试保留。新增 `tests/focus-browser.cjs`，使用 6 个已开资源与长标题，在 1611×928、1440×900、1024×768、390×844、320×640 下检查：

- 桌面正文滚动视口距顶不超过 120px，手机不超过 170px（查找栏关闭、设置弹层关闭时）。
- 规则正文维持 15px，避免通过缩字制造空间改善。
- 参照弹层打开不改变正文视口顶部；弹层在可视范围内，键盘焦点可返回。
- 专注前后可见原文区间、左右标签/参照、原文复制、主题与搜索恢复不回退。

CI 上传真实页面截图、几何测量 JSON 与测试摘要；浏览器接口为确定性模拟数据，不等于生产后端/真实设备全浏览器验证。本 PR 不自动合并或部署。
