# Web 前端视觉风格与交互逻辑规范

本文档记录 `trpg.chordvers.org`（`web/frontend/`）当前正式生效的视觉风格基调、核心交互机制与防回退红线，供后续迭代与多 Agent 协作衔接时对齐。

> 历史背景补充：底层原文区间模型见 `docs/frontend-archive-ux.md`，多标签与历史比对边界见 `docs/frontend-reading-workbench.md`，战术桌见 `docs/tactical-tabletop.md`。若与旧文档在视觉样式描述上存在出入，**一律以本文档为准**。

---

## 1. 世界观定位与审美红线

宏观界域是**无限流跑团（高维轮回兑换终端）**资料库，同时容纳战技侧、神秘侧、科技侧、特殊侧等跨晶壁系设定。前端设计必须保持克制、精密、中立的高维终端质感：

1. **严禁退回通用后台模板风**：禁止使用大圆角气泡卡片、廉价弥散阴影、厚重双层嵌套外框或 `#79b8ff` 之类的通用 SaaS 浅蓝色。
2. **严禁偏向单一题材风**：禁止套用中式宣纸/朱砂古籍风、西幻羊皮卷风或花哨霓虹赛博风，避免与跨世界观词条冲突。
3. **严禁英文凑数装饰词**：全站界面保持地道中文表达（如「轮回强化序列总枢」「序列分区」「四大侧别」），禁止塞入 `NEXUS / TIER / SYSTEM READY` 等无实质意义的纯大写英文装饰词。
4. **几何与分割准则**：全站圆角收敛为 `2px` 微切角（`--r-radius: 2px`），优先用 `1px` 细分割线、左侧 `2px`–`3px` 状态色脊与留白来组织信息，不靠堆叠盒子划分区域。

## 2. 双主题色板与侧别标识

主题变量集中定义于 `web/frontend/src/style.css` 与 `web/frontend/src/realm.css`，在 `:root` 上直接绑定 `color-scheme` 以同步浏览器原生滚动条与控件：

- **虚空棱镜暗色（默认）**
  - 背景层级：`#0b0d11`（主底色） / `#11151c`（面板） / `#161b24`（微抬升层）
  - 核心强调：`#73ded0`（星界棱镜青，主交互与激活态） + `#e5c07b`（星辉金，品阶/编号注记/战术桌入口，与站内战术桌同源呼应）
- **白昼终端亮色（`[data-theme="light"]`）**
  - 背景层级：`#f3f5f8`（冷灰底） / `#ffffff`（阅读纸面） / `#eef2f6`（次级底）
  - 核心强调：`#0d7a73`（深棱镜青） + `#9a6700`（深琥珀金），保证白底正文与边框对比度清晰
- **四大侧别固定语义色**（必须搭配方形色点或文字，不单靠颜色表意）：
  - 战技侧：`#f07167`
  - 神秘侧：`#b497ff`
  - 科技侧：`#5cc8ff`
  - 特殊侧：`#e5c07b`

## 3. 核心版块结构规范

1. **顶栏（`src/components/Header.tsx`）**
   - 左侧为 `2px` 微切角方形 `∞` 棱镜徽记 + 站名 + 等宽字体的「`已收录 N 项序列`」。
   - 导航页签（公开序列 / 最近更新 / 结团统计 / 后台）采用底部 `2px` 激光横线指示当前页，不使用胶囊按钮背景；右侧「`战术桌 ↗`」以 `1px` 竖线分隔并保持星辉金独立入口。
2. **左栏筛选（`src/components/FilterRail.tsx`）**
   - 「序列分区」为无边框平铺行，激活项显示左侧 `2px` 棱镜青竖线，右侧对齐等宽数字计数。
   - 「四大侧别」固定为 `2×2` 锐角象限矩阵按钮，带方形侧别色标；底部保留本地收藏夹列表。
3. **中栏检索列表（`src/components/ResourceCard.tsx`）**
   - 采用 `react-window` 固定 `104px` 行高（**严禁随意改动行高常量以免虚拟列表错位**）的无外框平铺索引条（`border-bottom: 1px solid`）。
   - 首行左起展示等宽序列编号（如 `001`，不加 `#`）、侧别色标与右对齐大类标签；当前打开项以左侧 `2px` 棱镜青竖线高亮。
4. **首页总枢与正文阅读器（`src/components/Reader/index.tsx`、`AdaptiveDocument.tsx`）**
   - **轮回强化序列总枢**（未打开任何档案时的默认页）：展示 `1px` 十字准星分割的 `2×2` 四大侧别象限矩阵、6 格等宽终端指标带、快捷检索框与「随机抽取序列」入口。
   - **档案头部与页脚**：顶部展示等宽 `编号 001` 导引行，`h1` 严格等于原始资源标题（**不得在 `h1` 内拼接前后缀，否则会破坏无损测试断言**）；`复制全文`、`下载 TXT`、`分享档案`、`档案信息` 采用克制的下划线文字动作；免责声明固定置于正文底部页脚，不挤占首屏。
   - **正文章节与能力模块**：阶段/大节标题渲染为无框横梁（`◆` 菱形标记 + 横贯 `1px` 细线 + 右侧括号兑换注记）；具体能力条目渲染为左侧 `3px` 品阶色脊的 `2px` 微切角模块，消耗/冷却/距离等短属性收敛进 `1px` 单元格分割的横向参数条。
   - **右侧目录导引轴**：桌面宽屏（容器 `>= 920px`）在右侧常驻无外框、`1px` 左竖线锚点目录，随滚动高亮当前条目。

## 4. 交互逻辑与防踩坑铁律

### 4.1 100% 原文无损铁律（最高优先级）
- 前端仅做展示增强，绝不篡改设定文本：`Reader/adaptive.ts` 将原始文本切分为连续区间 `[start, end)`，必须满足 `sections.map(s => s.raw).join('') === content`。
- 「复制全文」直接写入接口返回的原始 `content`；「复制此段 / 复制原文」直接写入对应区间的 `raw` 原文切片，**严禁从解析后的展示字段反向拼装字符串**。
- 开启「文内精确查找」输入关键词高亮时，首部制作人/修改人/审核人徽章及更新日志必须继续保持结构化排版并在内部高亮命中词，**不得退化回未排版的纯文本块**。

### 4.2 多栏工作台与状态保持
- **栏位折叠与专注模式**：左栏（索引）与中栏（结果）支持独立收起并持久化至 `localStorage`；开启「专注阅读」会临时隐藏顶栏、工作台标签栏与侧栏（释放 `>= 70px` 纵向阅读空间），退出后自动恢复原栏位状态。
- **多档案标签与并排对照**：已打开词条以完整路径去重保留在标签栏（最近 30 条存入 `sessionStorage`）。开启「并排对照」固定右侧参照档案、左侧可自由切换标签，两侧独立滚动且 DOM 锚点隔离；点击「退出并排」必须同步重置专注态，防止顶栏残留隐藏。
- **快捷键与路由**：`Ctrl/⌘ + K` 在任意折叠状态下自动展开结果栏并聚焦搜索框；词条切换走 `pushState`，筛选输入走 `replaceState`，完整兼容浏览器前进/后退与中文输入法合成态（IME）。

### 4.3 平板与手机端响应式逻辑
- **平板端（`821px–1180px`）**：自动收起常驻左栏，转为「结果列表 + 阅读正文」双栏，筛选条件通过原生 `<dialog>` 弹窗抽屉呼出。
- **手机端（`<= 820px`，含 `390px` / `320px` 小屏）**：
  - **单栏推入流**：未选词条时全屏显示检索列表，点开词条后自动切为全屏阅读页，通过工具条左上角「`← 结果`」或「`搜索档案`」一键返回并保留原搜索位置。
  - **折叠与触控热区**：顶栏导航折叠进右上角「`导航 ▾`」菜单，筛选与收藏收进「`索引 / 收藏`」全屏抽屉；主操作按钮保证 `44px` 触控高度，正文内联下划线文字动作保持紧凑行高避免撑裂排版。
  - **阅读器手机减负**：阅读工具条压缩为单行（高度 `<= 48px`）；能力模块去掉左右外边距改为贴边通栏（规则文本有效宽度 `>= 视口宽度 - 36px`），底部留出 `env(safe-area-inset-bottom)` 安全区；并排对照在手机端自动转为上下单栏页签切换；搜索框与查找框字号固定 `16px`，防止 iOS 点击输入框自动放大页面。

## 5. 关键文件索引与本地验收命令

### 核心文件目录
- 应用状态与响应式编排：`web/frontend/src/App.tsx`
- 顶栏 / 左栏筛选 / 列表项：`web/frontend/src/components/Header.tsx`、`FilterRail.tsx`、`ResourceCard.tsx`
- 阅读器 / 原文区间解析 / 工作台：`web/frontend/src/components/Reader/index.tsx`、`AdaptiveDocument.tsx`、`adaptive.ts`、`Workbench.tsx`
- 样式体系：`web/frontend/src/style.css`（设计变量与全局骨架）、`realm.css`（终端组件与阅读排版）、`workbench.css`（多标签/对照/结团统计/最近更新）、`reading-layout.css`（目录导引轴/专注模式/平板与手机响应式）

### 修改前端后的必跑检查
在 `web/frontend/` 目录下执行：
```bash
# 1. 类型检查、生产打包与静态 SEO 条目页生成
npm run build

# 2. 原文区间无损切分与工作台状态单元测试
node --test tests/*.test.cjs
```
若涉及布局、折叠栏、并排对照或移动端样式改动，需额外跑 Playwright 浏览器回归脚本（`tests/browser.cjs`、`tests/workbench-browser.cjs`、`tests/reading-layout-browser.cjs`），确保 `320px / 390px / 768px / 1024px / 1440px` 全视口零溢出、零断言回退。
