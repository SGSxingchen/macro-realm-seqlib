# 创作者别名词典

网站的创作者列表、资源计数和筛选统一使用标准名，资源原稿中的署名保持原样。

词典位于 `web/backend/app/author_aliases.py`：左边是标准名，右边列出明确对应的别名。新增或调整后重启后端以重建索引，无需修改前端或资源文件。

- “龙、1828女士、审判与正义之龙、奥莱特希雅”等统一为“龙娘”；“帝国”独立。
- “糕、糕子”统一为“糕手”。
- 其余条目结合昵称语义、错字、同一 QQ、复合署名及同稿件上下文逐项关联；确认后写入明确对应关系。
- 同一资源中出现多个相同创作者别名，只计一份；旧别名筛选链接继续有效。
- 审核、复查仍不计入创作者；未登记别名保持原样，不按名字相似程度自动合并。
- 名字中括号内的顿号不切开；已登记的复合署名先整体识别。同一括号中切换到“审核人：”后，其后人员不计入创作者；匿名及审核占位符保留在原文中，不作为独立创作者统计。
- 伪龙独立；大凯与小凯独立；半条咸鱼干、咸鱼、一条很咸的鱼各自独立。“一般路过北京热心群众”归沧羽，“阿虎/阿龙”归阿虎。

维护时先确认身份，再将完整别名加入词典。近似名字、含糊昵称和没有姓名的碎句不自动归属。

本地验证：`python3 -m pytest -q tests/test_search_credits.py`，以及按 `web/README.md` 的后端启动环境执行 `web/backend/smoke_check.py`。
