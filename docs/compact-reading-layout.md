# 紧凑阅读布局

在已合并的界域阅读工作台之上进行独立布局修正，与未来的联机棋盘功能分开。

## 问题

旧版专注/并排模式堆叠了站点品牌栏、布局栏、标签栏、打开数量/模式栏、参照设置栏、窗格说明栏和阅读工具栏。横向空间释放了，但阅读正文仍然被推到很低的位置。

## 改动

1. 标签和并排/历史操作合并为一条工作台头部；打开数量只保留在标签栏辅助说明中，不再单占一行。
2. 参照选择与使用说明移入按需弹出的「参照设置」，不会推挤正文；交换主/参照仍为一键操作。Esc 返回触发器、点外部关闭、选择后关闭。
3. 主/参照身份并入阅读工具栏视觉标记，同时为两个区域提供可读标签；不再单列说明行。移动端保留明确的主/参照切换按钮。
4. 专注阅读、并排阅读或两栏都收起时压缩站点品牌栏，保留退出专注、展开边栏、搜索和站点导航，不把工具藏到无法恢复的位置。
5. 不降低规则正文字号，不改任何技能源文本或解析器。窄屏标签横向滚动、触控操作保持独立，不强塞双栏。

## 回归验证

沿用原有构建、原文/工作台单测和两套浏览器回归，增加 `tests/compact-reader-browser.cjs`。

新回归加载六个长标题标签，在 1440/1024/390/320px 下测量正文滚动区域顶部、剩余高度和横向溢出，验证原文字号、参考设置不推挤正文、Esc 和选择后的焦点恢复、主参照切换与交换。指标写入 `compact-layout-metrics.json`，实际界面截图随 Actions artifact 输出。阈值是测试验收目标，不是预先声称达成的实测结果。

所有浏览器测试使用模拟接口/测试正文，不能代替生产真实资料及 Safari/Firefox 实测。本文档不包含也不上传用户提供的规则书。

## 范围与回滚

不修改后台、鉴权、资源文件、发布部署配置或依赖锁文件。棋盘/联机仍在规划，不包含于本布局 PR。撤销此 PR 即可回滚，无数据迁移。
