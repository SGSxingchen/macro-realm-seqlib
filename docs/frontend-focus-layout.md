# 专注阅读：减少常驻顶部层级

本次只修阅读布局，基于已合并的 PR #1；不加入下一项独立功能，不修改规则数据、解析器、后端、历史身份匹配或依赖。

## 布局规则

1. 普通浏览保留品牌和全站导航。已有专注开关为开、并且正在阅读资源时，隐藏全站导航；退出专注立即恢复。不引入另一套可能不同步的 focus 状态，也不借助浏览器全屏权限。
2. 顶部仍保留退出专注、恢复边栏和搜索。手机在专注状态下也有可见退出入口。没有选中资源时不隐藏全站导航。
3. 已开资源标签和并排/历史操作合成一条工作栏；移除单独的“已打开 N 份”行。数量保留在可访问名称中，长标签横向滚动。
4. 固定参照不再占一整行。参照选择放在参照窗格工具栏的展开控件中，选择器悬浮显示，不挤动正文；交换仍在工作栏直接可用。支持 Esc、点击外部和焦点离开关闭。
5. 主/参照说明融入窗格工具栏，不再额外分配标签行。手机仍是主/参照单窗格切换；不在窄屏硬塞双栏。
6. 专注时缩减应用生成的标题区留白，阅读说明移至“档案信息”。原始正文内的标题、作者、更新记录、自由段落、条件和限制均不隐藏，不缩小正文字号。

## 状态与回退

全站头部仅在已有 focus 状态和 open-resource 状态同时成立时隐藏（CSS `:has`）。不支持此选择器的旧浏览器保留原全站头部，不丢操作入口。每个窗格用 inline-size 容器查询调整工具栏内容密度，避免只按整个屏幕宽度判断并排栏的空间。

工作台和 Reader 保持挂载；收起/恢复布局不清空正文位置、原文模式、标签或固定参照。Ctrl/⌘ K 的既有恢复搜索逻辑不变。

新增 focus-layout-browser.cjs：六份测试档案、1600/1024/821/820/390/320px、深浅色截图、顶部高度预算、选择参照不增高、Esc/外部点击关闭、专注前后 DOM 和阅读状态保留、快捷键恢复、完整原文复制及横向溢出。

CI 另外从 PR base revision 构建一次旧版，只供同尺寸/同数据的前后测量。基线和新版均使用隔离的模拟接口，绝不访问或修改生产数据。截图和量化结果在 `realm-archive-ui` artifact 内，重点查看 `focus-before-1600.png`、`focus-after-1600.png`、`focus-comparison.json`。

基线测量不作旧版断言；新版常驻顶部（从视口顶边到正文滚动区）在测试条件下不得超过桌面165px/手机235px。目录、文内查找等用户主动展开时不纳入默认高度预算。对任意后续功能的新增工具条，继续以该预算做回归。
