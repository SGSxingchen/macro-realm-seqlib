# 规范化审核任务说明

本目录专门用于存放“资源规范化”相关的审核任务与说明文档。

## 用途

- 批量规范脚本生成审核任务 JSON。
- 人工审核页面 `/normalize-review` 读取这里的任务并展示规范化前后对照。
- 审核人确认规范化结果没有改变规则含义后，在页面中签名。
- 当前规则为凑齐 1 个签名即视为该规范化任务通过。

## 任务文件

每个审核任务使用一个 `{id}.json` 文件，至少包含：

- `id`：审核任务 ID。
- `resource_path`：被规范化的资源路径。
- `title`：资源标题。
- `original_content`：规范化前文本。
- `normalized_content`：规范化后文本。
- `signatures`：审核签名列表。
- `status`：`pending` 或 `approved`。

## 规范化边界

批量规范只能做格式统一、字段归位、明显同义字段替换和人工可复核的差异清单。

不得自动改动规则含义、数值强度、规则书词条适用性、冷却/持续结算方式，存在疑义的内容必须交给人工复核。
